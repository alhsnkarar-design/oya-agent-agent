## ⚙️ أوامر التشغيل (مرجع سريع)

> ⚠️ **راجع الـ README بتاع كل مشروع يوم التصوير**: الأوامر وأسماء الموديلات والإصدارات بتتغير.

```bash
# 1 Ollama (Linux/macOS، وعلى ويندوز في برنامج تثبيت من الموقع)
curl -fsSL https://ollama.com/install.sh | sh
ollama run <model-name>        # اختار موديل من مكتبة ollama.com

# 2 Open WebUI
pip install open-webui && open-webui serve

# 3 Jan / 4 AnythingLLM / 7 Upscayl / 28 AFFiNE ← برامج سطح مكتب تتنزّل من موقعها

# 5 Whisper
pip install -U openai-whisper
whisper lecture.mp3 --language Arabic --model medium --output_format srt

# 6 rembg
pip install "rembg[cli]"
rembg p input_folder/ output_folder/

# 8 n8n
npx n8n

# 9 Flowise
npx flowise start

# 10 Dify
git clone https://github.com/langgenius/dify && cd dify/docker
cp .env.example .env && docker compose up -d

# 11 Browser Use
pip install browser-use

# 12 Aider
python -m pip install aider-install && aider-install

# 15 Astro
npm create astro@latest

# 16 shadcn/ui
npx shadcn@latest init

# 17 Supabase (محليًا)
npx supabase init && npx supabase start

# 18 PocketBase ← نزّل الملف من الموقع ثم:
./pocketbase serve

# 19 Strapi
npx create-strapi@latest my-cms

# 20 Ghost (محليًا)
npm install ghost-cli@latest -g && ghost install local

# 22 Coolify (على سيرفر Linux)
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | sudo bash

# 24 Uptime Kuma
docker run -d --restart=always -p 3001:3001 -v uptime-kuma:/app/data --name uptime-kuma louislam/uptime-kuma:1

# 26 Docling
pip install docling && docling document.pdf

# 13 MCP Servers ← github.com/modelcontextprotocol/servers
# 14 Agent Skills ← github.com/anthropics/skills
# 21 Hoppscotch ← hoppscotch.io (أو Self-host بـ Docker)
# 23 Umami / 25 Stirling-PDF / 27 Immich ← Docker Compose من الـ README
```
