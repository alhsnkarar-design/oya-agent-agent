# مدار — تصميم واجهات تطبيق وكيل الذكاء الاصطناعي

واجهات هاتف (390×844) بهوية موحّدة، عربية افتراضيًا مع اتجاه RTL.

لوحة التصميم التفاعلية: https://claude.ai/artifact/7R9FqcpBzeEFoHKXytYi15

| # | الملف | الشاشة |
|---|------|--------|
| 1 | `Main.dc.html` | الرئيسية — وضع AI Agent |
| 2 | `ChatHome.dc.html` | الرئيسية — وضع Chat |
| 3 | `Task.dc.html` | المحادثة أثناء التنفيذ وظهور النتيجة |
| 4 | `Podcast.dc.html` | تحويل النصوص والكتب والملفات إلى صوت وبودكاست |
| 5 | `Motion.dc.html` | الموشن جرافيكس والتأثيرات البصرية |
| 6 | `AutoEdit.dc.html` | المونتاج التلقائي للفيديو |
| 7 | `VideoEdit.dc.html` | تعديل الفيديو بالأوامر النصية |
| 8 | `Dubbing.dc.html` | دبلجة الفيديو |
| 8ب | `DubbingVoices.dc.html` | قائمة 20 صوتًا و15 نبرة |
| 9 | `Voice.dc.html` | المساعد الصوتي المباشر |

## الهوية البصرية

- الخلفية `#0A0A12`، الأسطح `#12121C` / `#1A1A27`، الحدود `#222232`.
- النص `#F3F2FA`، الثانوي `#B4B2C9`، الخافت `#8A88A3`.
- البنفسجي (وضع AI Agent): تعبئة `#6A58E8`، لمسة `#9B8CFF`.
- السماوي (وضع Chat): `#5CD3F5` مع نص داكن `#06141B`.
- النجاح `#5BE3A6`.
- الخطوط: Readex Pro للعناوين، IBM Plex Sans Arabic للنصوص.
- الشعار: نواة تدور حولها مدار — يتكرر في الخلفية وفي كرة المساعد الصوتي.
