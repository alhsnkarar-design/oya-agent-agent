# «البطاقة» — بأسلوب الخطوط الذهبية (line-art infographic)

فيديو طولي 1080×1920، مدته 73 ثانية، بنفس أسلوب الفيديو المرجعي:
- خلفية فحمية، وخطوط ذهبية وبيضاء رفيعة ترسم نفسها.
- رجل خطي بلا ملامح وبهالة ذهبية.
- رسوم بيانية متحركة.
- عناوين بالعامية المصرية، والحديث بالفصحى أسفل الشاشة.

**الحديث:** رواه الترمذي (2639) وابن ماجه، وصححه الألباني. **التنبيه:** البطاقة ثقُلت لصدق قائلها ويقينه، كما قرّر أهل العلم.
