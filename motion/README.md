# مولّد الموشن العربي

جملة عربية تدخل، فيديو موشن جرافيكس MP4 يخرج. أول جزء من موقع Zifidit.

## الاستخدام

```bash
cd motion
npm install
npm run make -- "لو المشاهد *لاحظ* القطع، يبقى القطع غلط" --style build --ratio 9:16 --handle @zifidit
```

الفيديو يُحفظ في مجلد `out/`.

| الخيار | القيم | المعنى |
|---|---|---|
| الجملة | أي نص عربي | ضع الكلمة المهمة بين نجمتين `*كلمة*` لتظهر بالزعفراني وأكبر |
| `--style` | `build` · `punch` · `reveal` | شكل الحركة (تحت) |
| `--ratio` | `9:16` · `1:1` · `16:9` | ريلز وتيك توك · إنستجرام مربع · يوتيوب |
| `--handle` | مثل `@zifidit` | اسم الحساب صغير أسفل الفيديو (اختياري) |
| `--out` | مسار ملف | اسم ملف الإخراج (اختياري) |

## الأشكال

- **build:** الكلمات تدخل واحدة واحدة من اتجاهات مختلفة، وتتجمع لتكوّن الجملة. الكلمة المهمة تقفز وتحتها خط يُرسم.
- **punch:** كلمة واحدة ضخمة في كل لحظة، والكلمة المهمة بوميض واهتزاز. أسرع وأقوى للخطافات.
- **reveal:** الجملة تُكشف سطرًا سطرًا بخط مضيء يمسح من اليمين لليسار.

بدون موسيقى ولا مؤثرات صوتية. المدة تُحسب تلقائيًا من طول الجملة (حوالي 5–8 ثوانٍ لجملة متوسطة).

## فيديو الإعلان (Promo)

```bash
npm run promo
```
يُخرج `out/promo.mp4`: إعلان 9:16 مدته حوالي 44.5 ثانية، متزامن مع الفويس أوفر `public/voiceover.wav` يشرح مميزات Zifidit بالموشن والمؤثرات، في 9 مشاهد:
خطاف (مقاطع فوضوية تتنظم) ← المشكلة ← ظهور الاسم ← مونتاج تلقائي ← موشن من وصف ← تعديل بالصوت ← كابشن باللهجات ← مقاس لكل منصة ← دعوة للحجز.
الكود في `src/promo/`: `kit.tsx` (المكونات المشتركة) و`scenes.tsx` (المشاهد) و`Promo.tsx` (الترتيب والانتقالات).

## الإعلان 3D بالصوت

```bash
npm run promo3d
```
يُخرج `out/promo3d.mp4` (44.5 ثانية) فيه الفويس أوفر المصري جوه الفيديو: كاميرا واحدة بتطير بين 9 محطات، كل محطة جملة من الصوت.
الصوت نفسه بيحرّك المؤثرات: الكرة في مشهد التعديل بالصوت، وأعمدة الكابشن، ولمعان النجوم.
الكود في `src/promo3d/`، والأدوات المشتركة للـ 3D في `src/three/`.

## الحلقة 0 (3D)

```bash
npm run ep0
```
يُخرج `out/ep0.mp4`: عالم ثلاثي الأبعاد حقيقي (three.js) بكاميرا واحدة بتطير بين 6 محطات، مع Bloom وتشتت ألوان وحبيبات وإطار مظلم.
الكود في `src/ep0/`: `camera.ts` (مسار الكاميرا) و`world.tsx` (المجسمات والمؤثرات) و`Ep0.tsx` (النص العربي فوق المشهد).
الرندر بيستخدم WebGL برمجي (`swangle`)، فبياخد حوالي 8 دقايق.

## المعاينة الحية

```bash
npm run studio
```
يفتح Remotion Studio في المتصفح لتعديل الجملة والشكل ومشاهدة النتيجة فورًا.

## التقنية

- **Remotion 4:** يكتب الفيديو بـ React ويصدّره MP4 (H.264).
- **Noto Kufi Arabic:** الخط محمّل من ملفات المشروع نفسه.
- **الحركة على مستوى الكلمة**، وليس الحرف، حتى تبقى الحروف العربية متصلة.
- **على هذا الجهاز** يستخدم Chrome المثبت مسبقًا. على جهازك، Remotion ينزّل نسخته تلقائيًا أول مرة، أو تحدد مسار Chrome بـ `REMOTION_BROWSER`.
