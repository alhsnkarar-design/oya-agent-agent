# بزنس من الصفر · الحلقة 0 — إعادة تصميم (Zifidit)

إعادة تصميم كاملة للفيديو الأصلي (1080×1920، 24 ثانية، 30fps) كـ **موشن جرافيكس برمجي** يُرندر إطارًا بإطار:

- **شخصيات من الجمادات، بلا وجوه ولا ملامح** (خارج حكم تصوير ذوات الأرواح): ليس في الفيديو أي إنسان أو حيوان أو وجه أو عين أو فم.
  - **اللمبة "الفكرة"** (البطل): تقفز بأسلوب الضغط والتمدد (squash & stretch)، ويعبّر نورها عن الحالة: برتقالي للحماس، أحمر يرتعش عند الغلطة، أخضر مع النجاح. توهجها ينبض مع كل جملة.
  - **الجنيه:** عملة تقفز من بطاقة "كل جنيه" وتدور وترتد، ثم تعود في النهاية.
  - **مؤشر الماوس:** يكتب الطلب ويضغط زر الإرسال، ثم يضغط زر "تابع".
  - **مكعبات البناء:** تسقط وتُبنى هرمًا في مشهد "ولسه بنبنيه"، ثم تقفز اللمبة فوقه.
- **موشن جرافيكس:** إظهار الكلمات العربية كلمة بكلمة (يحافظ على تشكيل الحروف)، كروت زجاجية، متصفح ثلاثي الأبعاد، شريط تحميل، مسارات نجاح/فشل متوهجة، زر متابعة تفاعلي.
- **تأثيرات بصرية:** جسيمات فيزيائية (عملات، كونفيتي، نجوم)، موجات صدمة، Glitch/RGB split، خطوط سرعة، Aurora خلفية متغيرة الألوان لكل مشهد، Grain، Vignette، فلاشات، Camera punch-in & shake، انتقال دائري.
- **تصميم صوتي إجرائي:** موسيقى (Pad + Bass + Drums + Arp) ومؤثرات (whoosh، pop، impact، coin، glitch، typing، chimes) متزامنة مع الأحداث.

## التشغيل
```bash
npm i playwright           # Chromium مطلوب
node render.js             # -> out/video_silent.mp4
python3 audio.py           # -> out/audio.wav
ffmpeg -i out/video_silent.mp4 -i out/audio.wav -c:v copy -c:a aac -b:a 192k -shortest zifidit_ep0_redesign.mp4
```
افتح `index.html` في المتصفح لمعاينة حيّة متكررة. لقطات سريعة: `node render.js --stills 1.5,6,13`.
