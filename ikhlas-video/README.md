# «الثلاثة أول من يُقضى عليهم يوم القيامة» — فيديو توعوي

فيديو طولي 1080×1920، مدته 96 ثانية، مبني على حديث صحيح مسلم (1905)، بشخصيات بلا ملامح وجه، مع كابشن بالفصحى من نص الحديث. لا يُجسَّد الله تعالى (يُرمز للحساب بنور من الأعلى)، ولا مشاهد عنف أو تعذيب.

| الوقت | المشهد |
|---|---|
| 0–11 | ثلاثة رجال تتوهج أعمالهم ذهبًا، ثم تتشقق |
| 11–33 | المقاتل: يقاتل والناس يهتفون، ثم يُؤتى به، ويدّعي، فتتشقق كرة عمله عند «كذبتَ… فقد قيل»، ثم يغيب في الوهج الأحمر |
| 33–55 | العالم القارئ: يعلّم على منصة والجمهور يصفّق، ثم نفس مشهد يوم القيامة |
| 55–77 | المنفق: يتصدق والناس يصوّرونه بالجوالات، ثم نفس مشهد يوم القيامة |
| 77–86 | الحديث القدسي «أنا أغنى الشركاء عن الشرك» (مسلم 2985): عمل نصفه نور ونصفه ظل، فيُترك الظل |
| 86–96 | العلاج: صدقة في السرّ ليلًا، ثم شعار «أثر» |
