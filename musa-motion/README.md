# قصة موسى عليه السلام — موشن جرافيك بالأكواد

فيديو 1920×1080 · 30fps · 100 ثانية — مرسوم بالكامل بالكود (Canvas 2D إجرائي)، بدون نصوص على الشاشة، وبدون تجسيد لأي نبي: القصة تُروى بالرموز والضوء والطبيعة.

**الفيديو النهائي:** `video/musa.mp4`

## المشاهد
1. افتتاحية — جزيئات ذهبية تتجمع في نجمة إسلامية ثمانية
2. مصر وطغيان فرعون — أهرامات ومعبد ومشاعل وغبار
3. النيل — التابوت يطفو في هالة من نور
4. الخروج إلى مدين — كثبان وآثار أقدام وبئر وشجرة
5. جبل الطور — النار المباركة وأشعة النور
6. يوم الزينة — العصا تسقط وتصير حية من نور تبتلع الحبال
7. انفلاق البحر — عاصفة وبرق ثم جداران من الماء وطريق يابس
8. الخاتمة — فجر جديد فوق بحر هادئ

## التقنيات
- رسم إجرائي، وكل إطار دالة نقية في الزمن (تصيير متوازي حتمي)
- Parallax وإسقاط منظوري ثلاثي الأبعاد ومنحنيات Catmull‑Rom وضوضاء fBm وجزيئات بمزج إضافي
- معالجة لاحقة: Light leaks وVignette وحبيبات فيلم وأشرطة سينمائية
- مؤثرات صوتية مولّدة بالكامل (رياح، ماء، نار، رعد، ارتطامات) — بدون موسيقى

## إعادة البناء
```bash
pip install numpy scipy
python3 gen_audio.py      # soundtrack.wav
node render.js            # video/musa.mp4  (Playwright + ffmpeg)
node render.js --stills 10,40   # لقطات للمعاينة
```
افتح `index.html` عبر خادم محلي لمشاهدة تفاعلية.
